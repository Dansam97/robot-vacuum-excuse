Entry for the make.fun bounty "The Robot Vacuum's Best Excuse": a tiny Python program that writes one line — the funniest excuse a robot vacuum can give for missing a spot — to entry.txt. The excuse is rooted in the vacuum's own world: a corner mis-mapped as a cliff in 2023, a map it still trusts, and the sock it will not argue with.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
